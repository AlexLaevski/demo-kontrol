# Демо контроль — Python

| Файл | Задание |
|---|---|
| `task1.py` | Списки длиннее 3: третий элемент += сумма хвоста, хвост удаляется |
| `task2.py` | Вставка числа в убывающий список с сохранением порядка |
| `task3.py` | Словарь «имя → действие» из введённой строки, отсортированный по имени |
| `task4.py` | Сложение / умножение смешанных дробей (`1 1/2 + 2/3`) |
| `task5.py` | Уникальность значений словаря и ключ с максимальным значением |

Задания 2–4 проверяют ввод: на буквы, пустую строку, лишние операции и ноль в знаменателе программа пишет ошибку и переспрашивает.

Все задания одним ноутбуком: `demo_kontrol.ipynb`. Сайт: https://alexlaevski.github.io/demo-kontrol/

Запуск: `python3 task1.py`
