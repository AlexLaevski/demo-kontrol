Задание 1

Списки длиннее 3: третий элемент += сумма хвоста, хвост удаляется

# Решение 1.
lst = [[1, 2], [3, 4, 4, 3, 1], [4, 1, 4, 5]]
for s in lst:
    if len(s) > 3:
        s[2] = s[2] + sum(s[3:])
        del s[3:]
print(lst)

Словарь «имя → действие» из строки, отсортированный по имени. Неправильные куски показываются, строку просят ввести заново

# Решение 3.
while True:
    s = input('Строка: ')
    m = [p.split() for p in s.split(',') if p.strip()]
    ok = len(m) > 0
    for p in m:
        if len(p) != 2 or not p[0].isalpha() or not p[1].isalpha() or p[0][0].isupper() == p[1][0].isupper():
            print('Не понял кусок:', ' '.join(p))
            ok = False
    if ok:
        break
    print('Пиши через запятую пары из двух слов: Имя с заглавной, занятие со строчной. Пример: Иван ест, поет Оля')

print(dict(sorted({(a if a[0].isupper() else b): (b if a[0].isupper() else a) for a, b in m}.items())))

Задание 4

Калькулятор дробей (+ и *): числа вида 5, 2/3, 1 3/5. Буквы, лишние операции и ноль в знаменателе ловятся

# Решение 4.
from fractions import Fraction

def chislo(t):
    # t - части одного числа: ['5'], ['2/3'] или ['1', '3/5']
    if len(t) == 1 and t[0].isdigit():
        return Fraction(int(t[0]))
    if len(t) == 1:
        cel = 0
        drob = t[0]
    elif len(t) == 2 and t[0].isdigit():
        cel = int(t[0])
        drob = t[1]
    else:
        raise ValueError
    p = drob.split('/')
    if len(p) != 2 or not p[0].isdigit() or not p[1].isdigit():
        raise ValueError
    if int(p[1]) == 0:
        raise ZeroDivisionError
    return cel + Fraction(int(p[0]), int(p[1]))

while True:
    s = input('Выражение: ').replace('+', ' + ').replace('*', ' * ').split()
    if s.count('+') + s.count('*') != 1:
        print('Ошибка: нужна ровно одна операция + или *. Пример: 1 3/5 + 2/3')
        continue
    oper = '+' if '+' in s else '*'
    k = s.index(oper)
    try:
        f1 = chislo(s[:k])
        f2 = chislo(s[k + 1:])
        break
    except ValueError:
        print('Ошибка: числа пишутся так: 5, 2/3 или 1 3/5')
    except ZeroDivisionError:
        print('Ошибка: знаменатель не может быть 0')

if oper == '+':
    ans = f1 + f2
else:
    ans = f1 * f2

cel = ans.numerator // ans.denominator
ost = ans - cel
if cel != 0 and ost != 0:
    otvet = str(cel) + ' ' + str(ost)
elif cel != 0:
    otvet = str(cel)
else:
    otvet = str(ost)
print(' '.join(s), '->', otvet)
Вывод
Выражение: привет
Ошибка: нужна ровно одна операция + или *. Пример: 1 3/5 + 2/3
Выражение: 1/0 + 1/3
Ошибка: знаменатель не может быть 0
Выражение: 1 3/5 + 2/3
1 3/5 + 2/3 -> 2 4/15
