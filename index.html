Задание 1

Списки длиннее 3: третий элемент += сумма хвоста, хвост удаляется

lst = [[1, 2], [3, 4, 4, 3, 1], [4, 1, 4, 5]]
for x in lst:
    if len(x) > 3:
        x[2] += sum(x[3:])
        del x[3:]
print(lst)
Вывод
[[1, 2], [3, 4, 8], [4, 1, 9]]

Задание 2

Вставка числа в убывающий список с сохранением порядка

my_list = [7, 5, 3, 3, 2]
n = int(input("Новый элемент: "))
i = 0
while i < len(my_list) and my_list[i] >= n:
    i += 1
my_list.insert(i, n)
print(my_list)
Вывод
Новый элемент: 4
[7, 5, 4, 3, 3, 2]

Задание 3

Словарь «имя → действие» из строки, отсортированный по имени

s = "Иван ест, поет Оля, дома Борис, закупается Женя"
d = dict(sorted({(a if a[0].isupper() else b): (b if a[0].isupper() else a) for a, b in (p.split() for p in s.split(", "))}.items()))
print(d)
Вывод
{'Борис': 'дома', 'Женя': 'закупается', 'Иван': 'ест', 'Оля': 'поет'}

Задание 4

Сложение / умножение смешанных дробей

from fractions import Fraction

def chislo(t):
    p = t.split()
    if len(p) == 2:
        return int(p[0]) + Fraction(p[1])
    return Fraction(p[0])

e = input("Выражение: ")
if " + " in e:
    a, b = e.split(" + ")
    r = chislo(a) + chislo(b)
else:
    a, b = e.split(" * ")
    r = chislo(a) * chislo(b)
cel = r.numerator // r.denominator
ost = r - cel
if cel and ost:
    print(cel, ost)
elif cel:
    print(cel)
else:
    print(ost)
Вывод
Выражение: 1 1/2 + 2/3
2 1/6

Задание 5

Уникальность значений словаря и ключ с максимальным значением

d = {"a": 5, "b": 9, "c": 2}
print("Все значения уникальны:", len(set(d.values())) == len(d))
print("Ключ с наибольшим значением:", max(d, key=d.get))
Вывод
Все значения уникальны: True
Ключ с наибольшим значением: b
